# BEAUTIVA

Website static gratis untuk blog kecantikan.

## Isi
- Home
- Kategori Skincare, Makeup, Hair Care, Beauty Tips
- Template artikel
- About
- Contact
- Privacy Policy
- Area iklan
- Responsive mobile/desktop
- SEO dasar

## Cara pakai
Upload seluruh isi folder ini ke layanan static hosting gratis seperti GitHub Pages atau Cloudflare Pages.

## Sebelum dipublikasikan
1. Ganti email `hello@beautiva.example` di `contact.html`.
2. Tambahkan artikel asli secara rutin.
3. Buat halaman Terms jika dibutuhkan.
4. Hubungkan analytics dan jaringan iklan setelah traffic mulai tumbuh.
